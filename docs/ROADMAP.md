# Roadmap

## Phase 0
Repository foundation, protocol interfaces, deterministic simulator, CI, provenance schema.

## Phase 1
OBD-II PID decoder, DTC parsing, VIN/ECU identification, ELM327 transport.

## Phase 2
CAN + ISO-TP, UDS client, live-data pipeline, replay fixtures.

## Phase 3
Android Bluetooth/Wi-Fi, desktop SocketCAN/J2534, vehicle/ECU database for Iran.

## Phase 4
Actuator tests, service functions, advanced UDS, workshop reporting.

## Phase 5
Production hardening and diagnostic knowledge engine.
